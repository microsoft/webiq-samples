# Contributing

Follow the [repository contribution guidelines](../../../CONTRIBUTING.md),
including its CLA, code-of-conduct, attribution, and public-content requirements.

From this directory, use Node.js 22.12 or later and run:

```bash
npm ci
npm test
npm run build
```

Tests use mocked services and require no credentials. Keep the sample
customer-neutral. Do not commit local logos, exported settings, private data,
secrets, generated outputs, or deployment parameters.
